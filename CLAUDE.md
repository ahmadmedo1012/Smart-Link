## Performance guardrails (do not regress)
- No raw Tailwind palette colors (`amber/orange/purple/...`-NNN) — brand tokens only
- No `framer-motion` imports of any kind (type-only included — the dependency is gone; keep it that way)
- No new toast library — the contact form owns its inline error/success UI
- **Shadow utilities are generated from `@theme --shadow-*` entries (r9)** — a `--shadow-foo` variable in `:root` generates NOTHING in Tailwind v4 (the r9 audit found `shadow-glow` on 4 call sites rendering no shadow at all for the site's entire life). Runtime values live in `--t-*` vars (distinct names — a theme entry cannot reference its own name) so they switch per light/dark. Never write `shadow-[0_0_60px_var(--shadow-glow)]` (invalid embedded shadow) — use the generated `shadow-glow-strong`.
- **LCP elements (h1 + intro of every page) carry NO reveal animation (r9 generalization of r8)** — the eyebrow badge keeps `reveal-d1` for the cascade. `e2e/lcp-guard.spec.ts` enforces the raw HTML.
- `next.config.ts` carries a static CSP — if you add a third-party script/host (analytics, fonts, images), allow-list it in the CSP `script-src`/`connect-src`/`img-src` or it will be blocked. The two Unsplash hosts were REMOVED in r9 (zero remote images — keep the surface minimal).
- Above-the-fold content must render pre-JS (CSS reveal, never `initial={{opacity:0}}` wrappers)
- `next/image` for all raster content images
- Legal pages (privacy/terms) must stay pure Server Components
- **`mr-*`/`ml-*` physical spacing works only because the site is RTL-only** — prefer logical `ms-*`/`me-*` for any new code

## r13 additions (the details round — alpha-blind tools & silent-bug forensics)

- **Numeric contrast checks are MANDATORY for any color with alpha**: Tailwind compiles `text-*/NN` to `oklab(... / N)` which NO axe color-contrast probe resolves — 1.99:1 placeholder text passed every automated scan "green" (r13-H measured 89 pairs; the blind spots were exactly the alpha texts, resting borders and the sending state). Before shipping any `text-muted-foreground/NN`, `bg-*/NN` text or `color-mix()`: compute the WCAG ratio against the actual composited background. (The r13 reference script `scripts/r13-contrast.py` is not committed — the durable part is the pattern: read the token values directly from styles.css and compute.)
- **`--input-border`** (not bare `--border`) styles the form fields' RESTING border — WCAG 1.4.11 (3:1) for component boundaries; the error ring and focus ring were always compliant, the idle state was 1.10:1.
- **Icon regeneration must threshold the crop** (`alpha > 8`): 4 stray near-invisible pixels (alpha 1–3) inflated the logo mark's bbox from 329×327 to 330×395 and silently shrank the whole icon family from the designed 78% to 64% visible scale (and maskable 55%→45%, below the 50–60% recommendation). r11 measured the live mismatch but nobody found the dust until r13. Script: `scripts/r13-icons.py` (also quantizes to PNG8 — 64 colors is visually identical and ~8× smaller). (The script file is not committed; the alpha>8 threshold and the PNG8 rule are the durable knowledge.)
- **eslint ignores `playwright-report/**` and `test-results/**`**: running lint AFTER a test run otherwise drags the report's bundled vendor JS into the scan (thousands of phantom problems).
