## تشخيص الأداء (أسباب الدرجات المنخفضة)

### 1. الشعار العملاق — السبب الرئيسي
- `public/logo.png` = **2,061 KB** بأبعاد 1536×1024
- يُعرض في `main-nav.tsx` بحجم 150×38 مع `priority` (فوق الطية) → **هو عنصر LCP مباشر**
- LCP = **4.1 ثانية** (الهدف < 2.5 ثانية)
- Total byte weight = **2,831 KB** — الشعار وحده 74% منها

### 2. ترتيب العناوين (a11y - about/pricing فقط)
- `heading-order`: h1 → h3 (قفز على h2) في بطاقات القيم (about) وبطاقات الخطط (pricing)
- باقي تدقيقات a11y سليمة (100)

### 3. مؤشرات أخرى
- TBT = 250ms (مقبول) | CLS = 0 ✅ | Speed Index = 2.2s
- TTI = 13.5s (ثقيل — framer-motion + dynamic imports على شبكة محاكية 3G)
- Unused JavaScript = 48 KB (framer-motion)
- Mainthread work = 3.6s
