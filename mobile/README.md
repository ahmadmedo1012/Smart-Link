# SmartLink — Mobile (سمارت لينك)

تطبيق الهقة الرقمية لمنظومة Smart — **بوابة العائلة في جيبك**: تعرّف على
المنتجات الثلاثة (Smart Menu · SmartBot · Smart Order)، اطلع على
الخطط والأسعار بالدينار الليبي مع روابط المصادر الحيّة، وتواصل عبر
القنوات الصادقة — واتساب أولًا. **عربي RTL أولًا**، محتوى مضمّن يعمل
بلا إنترنت، وكل وصلة منتج تفتح عالمه الكامل.

الويب والبنية الكاملة: `README.md` جذر المستودع.

## البنية

```
mobile/
├── app.json                  هوية التطبيق (ly.smartlink.hub) — بلا App Links (أزيلت P36-G: النطاق ملك PWA الويب)
├── src/app/
│   ├── _layout.tsx           خطوط + بوابة RTL + تبويبات (رئيسية/أسعار/تواصل)
│   └── (tabs)/
│       ├── index.tsx         بوابة المنظومة: بطاقات المنتجات + لماذا Smart
│       ├── pricing.tsx       الباقات المجانية + سلالم المنظومة + الأسئلة
│       └── contact.tsx       واتساب + الشبكات + عن المنظومة
├── src/constants/content.ts  مرآة SITE + بيانات صفحة الأسعار (قانون الصدق)
├── src/constants/theme.ts    توكنات KODE الليلية (#050507 + #FF4C00)
└── src/lib/money.ts          الدينار الليبي (نفس عقد العائلة)
```

## قانون الصدق (موروث من الويب r137)

- الأسعار مرآة لكتالوجات المنتجات المنشورة؛ **الرابط الحي تحت كل جدول
  هو المصدر الوحيد** (`/pricing` لكل منتج).
- القنوات المعلنة هي المُراقَبة فعلاً: واتساب أولًا — لا بريد علني
  (هوية الإرسال الآلي ليست قناة دعم).

## إعداد

```bash
cd mobile
npm install            # Node 20+
npx expo start
```

## البوابات

```bash
npm run typecheck      # tsc --noEmit — صفر أخطاء
npm run lint           # expo lint
npm run test           # vitest — عقد الدينار
```

## البناء (GitHub Actions — لا حساب EAS مطلوب)

سير عمل `mobile-release.yml` جذر المستودع يبني عند الوسم `mobile-v*` أو
يدويًا: **Android APK موقّع** (من أسرار المستودع) + **iOS أرشيف غير
موقّع** (التوقيع لاحقًا بحساب Apple Developer) — الملفات تُرفع كـ
artifacts + GitHub Release.
